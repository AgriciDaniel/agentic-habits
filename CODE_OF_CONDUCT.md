# Code of conduct

## The short version

Be someone people want to review a pull request with. Disagree about the work,
never about the person.

## Specifics

- **Critique the habit, not the author.** "This trigger fires on everything" is
  useful. "This is careless" is not.
- **Bring the incident.** Assertions about what agents do are cheap. What
  happened, in what session, is worth reading.
- **Take a decision once it is made.** Sustained relitigation of a settled
  choice is the social version of guess stacking.
- **Assume the other person read the docs.** If they did not, link the section
  rather than making a point of it.

## Not welcome

Harassment, personal attacks, demeaning comments, unwelcome attention, publishing
someone's private information, and sustained disruption of discussion.

## Enforcement

Report to the maintainer through the address on the GitHub profile, or by
opening a private security advisory if you would rather it not be public.
Reports are handled discreetly. Consequences range from a request to change
behavior to a permanent block, decided by the maintainer.

## Scope

This repository, its issues and pull requests, and any space where someone is
representing the project.
