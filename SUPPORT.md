# Support

**A bug**: open an issue with the bug template. Include what you ran, what you
expected, what happened, your Claude Code version, and the file and line if you
know it. Paste the exchange.

**A habit proposal**: use the habit proposal template. Describe the incident,
not the principle.

**A security report**: do not open an issue. See [SECURITY.md](SECURITY.md).

**Never post** credentials, tokens, private repository contents, or client data
in an issue. If reproducing a problem needs any of those, say so and report it
privately instead.

**Not supported**: the agent failing to follow a habit. That is adherence, not a
defect, and the repair ladder in `skills/habits/references/review.md` covers it.
