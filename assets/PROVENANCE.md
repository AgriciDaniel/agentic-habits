# Asset provenance

What each visual asset is, where it came from, and whether it is cleared for
redistribution.

An earlier version of this file said the cover image's origin was "not
recorded" and that "the file carries no metadata chunks that would show it."
Both were false. The file carries a 23,617-byte C2PA manifest that records the
origin precisely. The sentence was written without opening the file, in the
document whose entire job is to say where things came from. It is corrected
below, and the episode is kept here rather than quietly deleted.

## What the manifest actually says

Read from the `caBX` chunk of `assets/cover.png`, not from memory:

- `c2pa.created`, 2026-08-29, `softwareAgent: gpt-image 2.0`
- `digitalSourceType: trainedAlgorithmicMedia`, which IPTC defines as "Created
  using Generative AI"
- `c2pa.converted` and `c2pa.watermarked.unbound`, same date
- `claim_generator_info: OpenAI Media Service API`
- Signature chain: `OpenAI OpCo, LLC` / `OpenAI Media Service`, issued under
  `SSL.com C2PA ICA R1 2025`

Verify it yourself:

```bash
python3 - <<'PY'
import struct
d = open('assets/cover.png','rb').read(); i = 8
while i < len(d):
    n = struct.unpack('>I', d[i:i+4])[0]; t = d[i+4:i+8].decode('latin1')
    if t == 'caBX': print(n, 'bytes of C2PA manifest'); break
    i += 12 + n
PY
```

The signature chain has **not** been cryptographically validated here. The
manifest is self-reported by the file. It is strong evidence of origin and it is
not proof.

## Rights

The image is machine output from a commercial image model, generated by the
maintainer. Whether the provider's terms convey the rights needed to
redistribute it under this repository's licence is a question about those terms,
and this file makes no claim about them. `NOTICE` therefore places the images
outside the MIT grant and says so, rather than asserting a conclusion nobody
here has verified.

If you are reusing this repository, treat the two images as all rights reserved
unless you check for yourself.
